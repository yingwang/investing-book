# 投资之道

一本关于投资的中文长读本，围绕三条主线展开：

1. 价值投资经典派
2. 指数化与被动投资
3. 行为金融与心理学

## 在线阅读

GitHub Pages: https://yingwang.github.io/investing-book/

## 本地预览

```bash
bundle install
bundle exec jekyll serve
```

打开 http://localhost:4000

## 结构

- `_config.yml` — Jekyll 配置
- `index.md` — 首页
- `preface.md` — 序言
- `part-1/` ~ `part-5/` — 五部正文
- `epilogue.md` — 结语

## 协议

本书内容仅供学习与思维参考，不构成任何投资建议。
