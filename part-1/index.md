# 第一部 投资的底层认知

在动手之前，先弄清楚自己在做什么，这是这本书第一部要做的事。

很多人在市场里待了很多年，账户上的数字起起伏伏，自己却从未真正回答过几个最基本的问题：

- 我现在做的，到底是投资，还是投机？两者真的有区别吗？
- 时间在我这边，还是不在？为什么有些人三十年攒下一笔像样的资产，有些人折腾一辈子还在原地？
- 我口口声声说"承担风险换取收益"，可我真正承担的，是什么样的风险？
- 我每天看的那个叫"市场"的东西，它的本质是什么？是一台精确的称重机，还是一个嘈杂的菜市场？
- 在所有可以投资的东西里，股票、债券、房产、商品、黄金、加密，它们各自是什么角色，凭什么有不一样的收益与波动？

这些问题听起来基础，甚至有点"哲学"。但凡是在市场里栽过跟头的人，多半都是栽在这些**基础却没想清楚**的地方，不是因为不知道答案，而是因为从未停下来真正问自己一次。

第一部不教你任何具体的操作。它要做的是**校准你的坐标系**：把"投资"这两个字背后的几个核心概念，投资与投机、复利、风险、市场、资产类别，重新拆开来看一遍，看看它们在你脑子里现在长什么样子，再看看它们应该长什么样子。

这一部分像是一副地图的图例：它不告诉你去哪里，但它告诉你"等高线代表什么、比例尺是多少、北在哪个方向"。如果图例错了，你后面所有的路线规划都是错的。

三条主线在这一部里都会初次出现。

- 关于**投资与投机的区分**，我们会从格雷厄姆 1934 年那个经典的定义说起，这是价值投资经典派的根。
- 关于**风险**和**市场**，我们会同时听一听有效市场假说的支持者和席勒、卡尼曼这些"不同意者"的声音，这是指数派和行为派最初的分歧地。
- 关于**资产类别**，我们会引入西格尔（Jeremy Siegel）那条著名的"两百年长期回报曲线"，这是后面所有资产配置讨论的起点。

读这一部的时候，请放慢一点。这五章里的每一个概念，你可能都"听说过"。但听说过和真正在脑子里建立起来，是两件事。第二件事，决定了未来几十年你账户上的数字。
