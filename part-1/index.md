# 第一部 投资的底层认知

在真正动手买卖之前，先想清楚自己到底在做什么，这是本书第一部要解决的事。

很多人在市场里摸爬滚打了许多年，账户上的数字起起伏伏，却从来没有认真回答过几个最基本的问题：我现在做的到底是投资还是投机，两者真的有区别吗？时间究竟站在我这边，还是站在我对面？为什么有人三十年下来攒下了一笔可观的资产，有人忙活一辈子却还在原地打转？我口口声声说“承担风险换取收益”，可我实际承担的到底是什么风险？每天盯着的那个叫“市场”的东西，本质上是一台精确的称重机，还是一个嘈杂的菜市场？在股票、债券、房产、商品、黄金、加密资产这些五花八门的去处里，它们各自扮演什么角色，凭什么给出不一样的回报与波动？

这些问题听起来很基础，甚至带点哲学味。但凡是在市场里栽过跟头的人，多半就栽在这些基础却没想透的地方。他们往往不是不知道答案，而是从来没有在热闹的行情里停下来，认真问过自己一次。

因此，第一部不教你任何具体的操作技巧。它要做的是先帮你校准坐标系，把“投资”背后的几个核心概念拆开来看一遍：投资与投机的边界、复利、风险、市场、资产类别。先看看它们现在在你脑海里长什么样，再看看它们本来应该长什么样。

这一部分好比一张地图的图例。图例不会直接告诉你该往哪里走，但它会标清楚等高线代表什么、比例尺是多少、正北在哪个方向。如果连图例都看错了，后面规划的所有路线都会跑偏。

全书的三条主线都会在这一部里初次登场：

- **投资与投机的区分**：从格雷厄姆 1934 年那个经典定义讲起，这是价值投资经典派的根基。
- **风险与市场有效性**：同时听一听有效市场假说的支持者与席勒、卡尼曼这些批评者的声音，看看指数派和行为金融派最初是在哪里分道扬镳的。
- **资产类别的长期回报**：引入西格尔（Jeremy Siegel）教授那条跨越两百年的长期回报曲线，作为后续所有资产配置讨论的起点。

读这一部时不妨放慢一点。这五章里的每一个概念你可能都听说过，但“听说过一个词”和“真正在脑海里立起一套框架”完全是两码事。后一件事，往往决定了未来几十年你账户上的最终数字。
