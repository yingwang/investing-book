# 第三部 指数化与被动投资

如果第二部讲的是"少数顶尖头脑如何持续战胜市场"，那么第三部要回答一个看似矛盾、却同样重要的问题：

**对于绝大多数人来说，最理性的选择，是承认自己赢不了。**

这不是一句泄气话。它是建立在六十年学术研究、五十年实证数据和无数普通投资者血泪经验之上的、一个清晰得近乎残忍的结论。

价值投资告诉你"市场先生有时候是疯子，你要利用他"。指数化投资则告诉你"绝大多数想利用市场先生的人，最后都被市场先生利用了"。它们看似对立，其实是同一枚硬币的两面——都建立在"承认市场长期向上、短期非理性"这个共同前提上，只不过价值派选择"在错误定价里挑选"，指数派选择"放弃挑选、整个买下来"。

这一部要讲清楚的不是"指数好还是主动好"这种二元对立，而是几件更基础的事：

- 一个叫约翰·博格（Jack Bogle）的人，是如何在 1975 年顶着整个共同基金行业的嘲笑，做出了那只后来改变了所有人投资方式的"愚蠢的基金"。
- 数据上到底有多少主动基金能持续跑赢指数——这个数字会让任何相信"我能选到好基金"的人重新审视自己的逻辑。
- 现代投资组合理论里那句被反复引用的话——"分散是投资里唯一的免费午餐"——到底是什么意思，为什么大类资产配置远比选股选时重要。
- 中国投资者最容易忽略的一件事：你账户里几乎全部是 A 股，但 A 股只占全球股票市值的不到 5%。
- 再平衡——这件听起来无聊得要命的事，为什么是普通人能做的、为数不多的"反人性而又有数学依据"的操作。
- ETF 这个工具，是怎么从指数化的好朋友变成投机的好工具的，怎样不被自己手里的工具反噬。
- 因子投资——介于主动和被动之间的灰色地带——它的承诺和它兑现不了的部分。

这一部读起来会比第二部"冷"一些。没有奥马哈年会的金句，没有 1973-74 年熊市里某只股票的传奇翻身。指数派从来不靠故事，它靠的是几条枯燥的数学事实和长达半个世纪的回测曲线。

但请你认真读完。因为说到底，这本书里我能给一个普通中国家庭最负责任的、最不冒险的一组建议，几乎都藏在这七章里。

行为金融那一部分——也就是第四部——会回过头来解释一件事：**为什么这套指数化的方法在数学上如此简单，在现实里却几乎没人能完整执行。** 答案不在数学里，在你的脑子里。
